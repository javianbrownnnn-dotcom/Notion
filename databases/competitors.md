# ⚔️ Competitors & Competitor Videos

Two databases: **Competitors** (one row per channel we study) and **Competitor Videos** (the swipe file — their outliers, which feed our Ideas).

---

## ⚔️ Competitors

> **Purpose:** Systematic intelligence on every channel we compete with or learn from. Answers: what's working in this niche, where are the gaps we can exploit?
> **Owner:** Founder 1 (CEO). **Instructions:** add via `New Competitor` template; refresh stats monthly (automation), refresh analysis quarterly.
> **Linked SOPs:** SOP-001 Research. **Related:** relates to Channels; feeds Ideas via Competitor Videos.

| Property | Type | Notes |
|---|---|---|
| Channel | Title + URL | |
| Our Channel | Relation → Channels | which of ours they compete with |
| Tier | Select | `North Star` (way bigger) / `Direct` / `Emerging` (watch) |
| Subscribers / Avg Views / Upload Frequency / Avg Length | Numbers | refreshed monthly — keep a dated log in page body for trend |
| Thumbnail Style | Multi-select + gallery in page | face / object / text-heavy / illustration / high-contrast … |
| Title Patterns | Text | their formulas, with examples |
| Storytelling Structure | Text | how they open, structure, pace |
| Hook Style | Text | first-30-seconds pattern |
| Monetization | Multi-select | AdSense / Sponsors / Affiliate / Course / Merch / Newsletter |
| Sponsor Types | Text | who buys them (feeds Founder 2's prospect list) |
| Affiliate Products / Newsletter | Text / URL | |
| Strengths / Weaknesses / What We Can Do Better | Text | the payoff fields — required, not optional |
| Top Videos | Relation → Competitor Videos | |

**Views:** `By Our Channel` (board) · `By Tier` · `Monthly Refresh Due`.

---

## 🎯 Competitor Videos (Swipe File)

> **Purpose:** Their outlier videos = proof of audience demand. The single best source of high-scoring Ideas.
> **Instructions:** Log any competitor video performing ≥ 2× that channel's average. 5 minutes per entry.

| Property | Type | Notes |
|---|---|---|
| Title | Title + URL | |
| Competitor | Relation → Competitors | |
| Views / Age (days) | Numbers | |
| Outlier Ratio | Number | views ÷ channel avg — sort key |
| Why It Worked | Text | required: hook, promise, packaging analysis |
| Thumbnail | Files | screenshot |
| Hook Transcript | Text | first 30s |
| Fed Ideas | Relation → Ideas | the conversion that matters |

**Views:** `Outliers` (ratio ≥ 3, unconverted to Ideas) · `By Competitor`.
