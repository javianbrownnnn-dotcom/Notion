# 🧠 Knowledge Base

> **Purpose:** Everything the company learns, made searchable: books, courses, breakdowns of great videos, industry reports, AI discoveries, and — most valuable of all — **lessons from our own published videos** (fed by every 30-day Performance Review).
> **Owner:** Founder 1. Everyone contributes.
> **Instructions:** A knowledge entry must end with an **"So what do we do differently?"** line — insight without a behavioral consequence is trivia. If the consequence is procedural, it becomes an SOP edit (link it).
> **Related:** fed by Videos (performance reviews), Competitors; feeds SOPs, Ideas, Channel story structures.

## Properties

| Property | Type | Notes |
|---|---|---|
| Entry | Title | |
| Type | Select | Book / Course / Video breakdown / Lesson Learned / Industry report / AI discovery / Research / Framework |
| Topic | Multi-select | Storytelling / Packaging / Retention / SEO / Monetization / Hiring / AI workflow / Niche research |
| Channel Relevance | Relation → Channels | blank = universal |
| Source | URL | |
| Added By | Relation → People | |
| Key Takeaways | Text | 3–5 bullets max — the searchable payload |
| Action Taken | Relation → SOPs / Text | what changed because of this |
| Rating | Select | ⭐1–5 usefulness |
| From Video | Relation → Videos | when it's a lesson from our own performance review |

## Views

`Recent` · `By Topic` · `⭐ Canon` (rating 5 — required reading for onboarding, linked from the People template) · `Lessons From Our Videos` (Type = Lesson Learned, by channel).
