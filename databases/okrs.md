# 🎯 OKRs & KPIs — Objectives, Key Results, Scoreboard

> **Purpose:** The management operating rhythm. Objectives (quarterly, qualitative) → Key Results (measurable) → reviewed weekly on the Company Scoreboard. This is how three founders with 21 responsibilities stay pointed at the same 3 things.
> **Owner:** Founder 1. Set quarterly in the Quarterly Planning meeting; graded, not vibes.
> **Instructions:** Max 3 Objectives per quarter company-wide; max 3 KRs each. If everything is a priority, nothing is.

## 🏔 Objectives

| Property | Type | Notes |
|---|---|---|
| Objective | Title | qualitative, inspiring, quarterly — `Q3: Prove the second channel` |
| Quarter | Select | `2026-Q3` … |
| Owner | Relation → People | ONE founder per objective |
| Key Results | Relation → Key Results | |
| Progress | Rollup | KRs → avg % |
| Status | Select | On Track / At Risk / Off Track / Done |
| Retro Notes | Page | graded at quarter end: score 0–1.0 + what we learned |

## 📏 Key Results

| Property | Type | Notes |
|---|---|---|
| Key Result | Title | `Publish 12 videos on [HIS] with ≥40% avg retention` |
| Objective | Relation → Objectives | |
| Metric / Start / Target / Current | Text + Numbers | Current updated weekly (automation from Snapshots where possible) |
| Progress | Formula | `(Current − Start) / (Target − Start)` |
| Channel | Relation → Channels | if scoped |
| Owner | Relation → People | |

## 📊 Company Scoreboard (the weekly KPI row — a linked view + a small `KPI Weekly` database)

One row per week; reviewed first in every weekly meeting. Filled by automation + 10 minutes of manual entry.

| KPI | Source | Why it's on the board |
|---|---|---|
| Videos published (per channel vs target) | Videos | consistency is the algorithm's first demand |
| Subscribers Δ / Views Δ (per channel) | Snapshots | growth |
| Avg CTR / Avg retention (published this month) | Snapshots | packaging & story quality |
| Revenue MTD by stream | Revenue | money + concentration risk |
| Cost per video (trailing 5) | Expenses | unit economics |
| Approved ideas in queue | Ideas | fuel-tank level — **red flag if < 2 weeks of production** |
| Sponsor pipeline weighted value | Deals | forecast |
| Newsletter subscribers Δ | manual/ESP | owned-audience hedge |
| Founder hours per published video | Tasks (Actual hrs) | is delegation real? |
| % pipeline stages executable by non-founder | SOPs audit | key-person risk burn-down |

## Views

`This Quarter` (objectives w/ KR progress bars) · `Scoreboard` (KPI Weekly, table by week) · `At Risk` · `History` (past quarters + retro grades).
