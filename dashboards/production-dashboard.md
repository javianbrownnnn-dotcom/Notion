# 🎬 Production Dashboard (Founder 3)

Scripts · editing · motion graphics · thumbnails · production management. Later: the Head of Production's screen, unchanged.

## Layout

**1. My Plate** — Tasks: Assignee = F3, not Done, by Due.

**2. 🏭 The Factory** — Videos board by Stage, all channels. Header: `⚠️ At Risk` (publish < 7 days, pre-QA) · `🔒 Blocked` tasks grouped by blocker.

**3. 🔓 Ready to Start** — Tasks where dependencies are Done, grouped by Stage: the pull queue. Never wonder "what next"; also the first view a new editor lives in.

**4. 📅 Content calendar** — Videos by Publish Date, month view, all channels (consistency = the KPI).

**5. ✂️ Stage batches** — tabs: all Scripts this week · all Edits · all Thumbnails · all VO. Batching identical work is how one person (then one team) stays sane across channels.

**6. 🎨 Asset & rights corner** — Assets `⚠️ Expiring 60d` · Videos in Editing whose `Assets Used` contain unproven licenses (must be empty before QA) · brand-kit links per channel.

**7. 👥 Team load** (grows in importance with each hire) — Tasks `Workload` board by Assignee · People `Capacity` view · freelancers on Bench.

**8. 📖 My SOPs** — SOP-002/003/004 quick links + SOPs owned by F3 flagged stale.

**9. 📥 Handoff inbox** — Videos entering production stages from upstream (Review approved → VO queue), sorted by Publish Date.

## Cadence

Daily: 1, 2, 3. Weekly: 4, 5, 7. Monthly: 6, 8.
